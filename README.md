# Simple Student Calculator

## Description
 simple c++ console program that calculates any operation the user puts and gives them a solution instantly
## How to Run 
1. Open the project folder in Xcode
2. Press Ctrl+F5 to build and run
3. Enter 2 values and an operation

##
Input: First Number: 20 Second Number: 8 Operation: *
Output: Solution: 160
